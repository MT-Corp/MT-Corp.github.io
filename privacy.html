Política de privacidad

Última actualización: 28 de septiembre de 2026

Atelier Tools es una aplicación para QR, escaneo, imágenes, documentos y PDF. Esta política explica cómo se tratan los datos cuando utilizas la aplicación.

1. Procesamiento local

Las funciones de creación, conversión, edición, OCR local y procesamiento de documentos se ejecutan en el dispositivo cuando la aplicación así lo indica. Los archivos seleccionados o creados por el usuario no se envían a servidores propios de Atelier Tools.

2. Archivos y proyectos

Los archivos, imágenes, proyectos y PDF se guardan en el dispositivo o en la ubicación que el usuario elija mediante Android. Atelier Tools no vende esos archivos ni los utiliza para crear perfiles publicitarios.

3. OCR y asistente documental

El OCR y el asistente documental local procesan el contenido en el dispositivo. El texto reconocido no se envía a servidores propios ni se utiliza para analítica del contenido.

4. Publicidad y consentimiento

Atelier Tools utiliza Google Mobile Ads para mostrar anuncios en las ubicaciones permitidas por la aplicación. Google y sus servicios publicitarios pueden procesar identificadores del dispositivo, información de uso, datos de diagnóstico y datos relacionados con la publicidad, conforme a sus políticas y a las opciones de consentimiento disponibles.

Consulta la Política de privacidad de Google y la divulgación de datos de Google Mobile Ads.

5. Compartir

Al utilizar compartir, Android muestra las aplicaciones disponibles. El archivo o texto se entrega únicamente a la aplicación que el usuario seleccione.

6. Permisos

La aplicación puede solicitar cámara, imágenes o documentos solamente cuando una función lo necesita. Puedes rechazar esos permisos; la función correspondiente dejará de estar disponible.

7. Retención y eliminación

Los archivos y proyectos permanecen en el dispositivo hasta que el usuario los elimina o utiliza las opciones del sistema para eliminarlos. Atelier Tools no mantiene una copia propia en servidores.

8. Menores

Atelier Tools no está diseñada específicamente para niños. No solicitamos deliberadamente datos personales de menores.

9. Cambios

Podemos actualizar esta política cuando cambien la aplicación, sus servicios o los requisitos legales. La fecha de actualización aparecerá al principio de esta página.

10. Contacto

Para preguntas sobre privacidad, escribe a mtcorp0505@gmail.com.
